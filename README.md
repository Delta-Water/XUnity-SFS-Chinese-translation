# XUnity-SFS-Chinese-translation
## 介绍
### 非官方的SFS汉化，用于为PC版添加迟迟未见的中文支持，旨在一定程度上改善玩家的游戏体验。
## 使用方法
### 配置好XUnity.AutoTranslator，将仓库中的文件下载并替换原有的翻译文件即可。
### 不知道如何配置的可前往官方文档、询问人工智能或去B站看我的视频，自用的配置文件也在仓库中
#### 出于对没有魔法的各位的照顾，示例文件中使用的的是彩云的接口，自己去注册一个填上就行，每月前百万字符免费，绰绰有余了
#### 喜欢百度的也可以去用百度的翻译服务，不过由于本人极度讨厌这个公司，在此不多说明
#### 有魔法的朋友直接把最开头的服务换成谷歌的就行，省心又免费。
#### 注：本汉化的思路是能用就行，肯定存在较大的优化空间和不够全面之处，欢迎各位吴彦祖做出积极贡献！
